# 골드 세금 6% 적립 (공성전 준비) — 카드 tasks/goldtax · 갈래 work/goldtax

## 프로듀서 요청 (11/5 원문)
"슬슬 공성전 업데이트에 앞서 골드 세금을 축적 시킬려고 하는데, 유저 3명이 상점,변신,인형뽑기, 텔레포트 등 게임내에서 사용하는 모든 골드의 6%를 누적시킬수 있어?"

## 팝업으로 정한 것
- **가격 그대로 · 6% 적립**: 유저가 내는 값은 지금과 같다. NPC에게 쓴 골드의 6%가 '아덴 성 금고'에 쌓인다 (나머지 94%는 지금처럼 사라짐). 가격을 올리지 않는다.
- **모두에게 보이기**: 위 메뉴 [랭킹] 창에 '아덴 성 금고 N 골드'(전체 합)와 '내가 낸 세금 N 골드'. 공성전 업데이트 때 성을 가진 혈맹이 받는 돈으로 쓸 예정.

## 세금을 매기는 곳 / 빼는 곳 (메인방 해석)
- 매김(게임=NPC에게 쓰는 골드 전부): 모든 NPC 상점 구매(잡화·무기·방어구·마법서·특별 탭 · 자동사냥 마을 정비 `AUTO.buyAll` · 오프라인 사냥 중 산 것) · 변신 카드·마법인형 뽑기와 전설 재뽑기 · 텔레포트·월드맵 이동비·입장료(잊섬 50만·콜로세움 입장권·할로윈 모자 등) · 강화·제작·합성·연금술 수수료 · 스탯 초기화·부활 등 골드로 사는 서비스 전부. `coins`가 줄어드는 곳을 전부 찾아(`coins -=`, `coins = coins - …`, `coins-=`, 함수로 빼는 곳까지) 분류한다.
- 뺌: 유저끼리 거래·시장(다른 유저 물건을 사는 거면 → 판 사람이 받는 돈이라 뺌, NPC 물건이면 매김 — 코드 보고 판단)·창고 골드 맡기기·파티 골드 나누기·사망 골드 손실·운영자 [지급/회수]·우편.

## 만드는 법 (추천안 — 더 나은 방법이 있으면 그걸로, 보고에 적기)
1. 한 곳 함수 `goldTax(amount, cat)` — 골드를 뺀 바로 뒤에 부름. 세금은 1/100 골드 단위 정수로 쌓아 오차 없이(`Math.round(amount * 6)` → `taxC`), 보일 때 `floor(taxC / 100)`. 세율은 상수 하나(`TAX_RATE = 0.06`).
2. **내가 낸 세금**: 계정 문서 `users/{uid}.goldTax` = `{ v:1, c:<1/100골드 누적>, s:<쓴 골드 누적>, by:{분류: 쓴 골드} }` — polyCards·dollCards처럼 `SAVE.loadStore`·`SAVE.now`에 넣고 읽기 실패면 덮어쓰지 않음(bad). 계정의 모든 캐릭터가 같이 쌓음.
3. **금고 합계(모든 유저)**: 랭킹(RANK — 봇 호스트 탭이 모아 Firestore `worldbot_chars/{bothost uid}`에 저장 · 중계 토픽 `adenworld/w1/world1/rk` retain · presence `kd`/`rke`)과 같은 길로 — 각 클라이언트가 자기 계정 누적 세금을 중계로 알리고, 봇 호스트가 uid별 최댓값을 모아 합계를 저장·retain으로 뿌린다. 접속 안 한 유저 몫도 사라지지 않게(봇 호스트 저장). 누적값을 보내므로 메시지를 놓쳐도 다음에 맞춰짐. 봇 호스트가 꺼져 있어도 각자 계정에 쌓인 값은 남는다.
4. **화면**: [랭킹] 창 위쪽에 '🏰 아덴 성 금고 N 골드 · 세율 6% · 공성전에서 성의 주인에게' + '내가 낸 세금 N 골드' (모바일 포함). 운영자 [살펴보기]에 그 계정의 세금, 운영자 창에 금고 합계·유저별.
5. 시작은 이번 배포부터(지난 소비는 세지 않음).
