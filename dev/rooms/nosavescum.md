# 결과 먼저 저장 (강제 종료로 강화 실패 되돌리기 막기) — 카드 tasks/nosavescum · 갈래 work/nosavescum

## 왜
- 게임은 서버 없이 클라이언트가 Firestore에 저장한다 (`SAVE` · 20초마다 · 창을 닫을 때 beacon).
- 그래서 강화가 실패(증발)한 걸 보고 20초 안에 게임을 강제 종료하거나 인터넷을 끊으면, 다시 켤 때 실패 전 상태로 돌아왔다 → 실패를 계속 되돌려 +18 방어구 같은 장비를 만든 것으로 보이는 유저가 있었다.
- 프로듀서와 정한 해결(11/6): **결과를 먼저 계정 서버에 저장하고, 저장이 끝난 뒤에 결과를 보여 준다.** 결과를 본 뒤 끄면 이미 저장된 뒤이고, 결과를 보기 전에 끄면 무엇이 나왔는지 모른다 → 되돌려도 고를 수 없다.
- 기록(로그) 남기기는 다른 갈래 `work/auditlog`가 따로 한다. 이 갈래는 '보여 주는 시점'만 바꿨다.

## 흐름 (`src/game.js` `const RSAVE` — INV 바로 앞)
1. 시작 전 `RSAVE.can('강화')`: 계정 서버를 쓰는데 `navigator.onLine === false` 이거나 최근 저장이 인터넷 문제로 실패했으면(`SAVE.offline()`) '인터넷 연결이 없어서 지금은 강화를 할 수 없어요'로 막고 저장을 한 번 다시 시도. 앞의 결과를 아직 기록 중이면 '앞의 결과를 기록하는 중이에요'로 막음.
2. `const K = RSAVE.begin()` → 상태 바꾸기(주문서·장비·카드·골드) → `RSAVE.then(K, 보여 주기)`.
   - begin을 상태 바꾸기 **앞에** 부른다: 그 순간부터 `INV.render`·강화 창 `bkRender`·변신/인형 창 `refresh`가 다시 그리지 않음(가방에서 아이템이 사라지거나 +수치가 바뀐 게 안 보임).
   - 저장은 `SAVE.now(false, true)` 한 번 (20초 자동 저장이 도는 중이면 끝난 뒤에). 바뀐 문서만 쓰므로 결과 1번 = 쓰기 1~2번(캐릭터 문서 + 계정 문서) · 읽기 1번(현재 접속 확인).
3. 저장 중: 가방·캐릭터·아이템 정보·강화·변신·인형·연금술·제작 창을 '기록 중…'으로 덮음(누르기도 막음 · 0.15초 뒤에 보임 — 빠르면 깜빡임 없음) + 위쪽 가운데 알림.
4. 저장 성공 → 결과(연출·소리·채팅·전체 공지·가방 다시 그리기) 공개.
5. 저장 실패(오프라인 등) → 결과는 계속 숨기고 '저장 확인 중 — 인터넷 연결을 확인해 주세요'로 2.5초마다 다시 저장. 3번 넘게 실패하면 '계속 연결되지 않으면 다음에 접속했을 때 가방에서 결과를 확인할 수 있어요' 안내. 성공하면 그때 공개.
6. 계정 서버를 안 쓰면(이 기기 저장 · 데모 `ADEN_DEMO` · 테스트 페이지 `DEMO_MODE` · 봇 호스트) `begin()`이 null → 지금처럼 바로 보여 줌.

## 대상 (운이 갈리는 것만 · 안전 강화 안·저주 주문서·장신구 변경처럼 결과가 정해진 건 그대로 바로)
- 강화 창 단일 강화(안전 강화를 넘는 것): `enGoOne` — 강화 연출(`ENHFX.play`의 `info.gate`)이 기운을 모으는 동안 저장 → 저장이 끝나야 [밀어서 결과 보기]가 나옴. 보통은 연출(1.3초) 안에 저장이 끝나서 기다림이 없다. 6초 넘게 저장이 안 되면 [닫기](결과는 안 보임 · 저장되면 채팅으로 결과).
- 강화 창 다중(일괄) 강화: 안전 강화까지는 그대로 한 번에. 그 뒤는 **묶음** — 증발이 나올 때까지(최대 6번) 미리 굴려 한 번 저장 → 저장되면 예전처럼 하나씩 보여 줌. 중지는 다음 묶음부터(이미 저장된 묶음은 바로 다 보여 주고 멈춤). 저장 수 = 묶음 수(대략 증발 수 + 1).
- 주문서 클릭 강화: 무기·방어구·할로윈 모자(안전 강화를 넘는 것) · 장신구(+1부터) · 축복 부여 · 속성 강화 · 고대의 주문서 · 장비 변경 주문서 (`applyScroll`).
- 주머니·상자: 아르카의 마법주머니 · 축복 주문서 주머니 · 수호탑 상자 · 할로윈 주머니 (`INV.use`).
- 연금술(`ALCH` 수동·자동): 계정 서버면 결과를 미리 정해 저장 → 돌아가는 연출(1.3초/0.65초)과 저장이 모두 끝나면 공개. (아니면 예전처럼 연출 끝에 굴림)
- 제작 장인: 가호 제작·가호 조합 40% (`CRAFT make·mix`).
- 변신 카드·마법인형(`mkCG`): 1회·11회·무료 뽑기 · 마일리지 전설 · 전설 재뽑기 · 자동·직접 합성. 11회도 저장 1번 후 한 번에. 저장 중엔 `busy`(다음 뽑기·Space 막힘)·창 다시 그리기 멈춤(`rsH`). 자동 뽑기는 오프라인이면 멈춤.
- 플레이 기록(`TELE.ev` → PC 로그 파일)도 결과를 보여 줄 때 남김.

## 감사 기록(work/auditlog)과 합친 방식 (11/6 merge)
- `audit('en'|'bless'|'chg', …)`은 결과가 정해지고 상태가 바뀌는 곳(저장 전 · `RSAVE.then` 바깥)에서 부름 → 결과를 보기 전에 꺼도 기록은 이미 서버로 감.
- 뽑기·합성·재뽑기·마일리지·고대의 주문서 벨트·연금술·수호탑 상자 골드는 원래 `TELE.ev`를 감싸서 기록했는데, 플레이 기록(PC 로그 파일 `TELE.ev`)은 결과를 보여 줄 때 남겨야 해서 둘을 나눔: 결과가 정해질 때 `audit('pre', 사건, o)`(감사 기록 + `o._au = 1` 표시) → 보여 줄 때 `TELE.ev(사건, o)` (감싼 쪽이 `_au`를 보고 다시 기록하지 않음 = 중복 없음).
