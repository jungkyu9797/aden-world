## 원칙 (지금 게임과 따로)
- 새 렌더러는 **별도 파일 `src/gl.js`** + game.js에는 최소한의 연결만 (렌더러 고르기 · 그리기 명령 넘기기). 다른 작업과 충돌을 줄이려고 game.js 수정은 몇 군데로 묶고 주석 `// GL:` 표시.

# ★ 11/1 프로듀서 결정 — WebGL은 **따로 여는 대화방(WebGL 방)**에서 진행
메인방은 게임 업데이트·질문을 바로바로 받아야 해서, WebGL 작업은 프로듀서가 새로 연 대화방 하나가 맡는다. 그 방의 규칙:
1. 시작: CLAUDE.md와 이 문서를 읽고 `git fetch && git checkout -B work/webgl origin/work/webgl` (지금 7090970: 0단계 시제품 `src/gl.js` = 기록용 가짜 2D 컨텍스트 → WebGL2 배치 · game.js frame 한 군데 연결 · 기본 꺼짐 · `dev/tests/gl_scene.js`·`gl_bench.js`는 작성 중이던 것 — 먼저 돌려 보고 이어서).
2. **자기 갈래 work/webgl에만** commit·push. main에 push하지 않음 · 배포하지 않음 · 메인 테스트 페이지를 올리지 않음(메인방 몫).
3. game.js 수정은 최소로, `// GL:` 표시. 다른 콘텐츠 작업과 부딪히지 않게 새 코드는 `src/gl.js`에.
4. 진행할 때마다 작업판 카드 `tasks/webgl`의 `status`(doing)·`phase`·`next`·`note`·`updated`를 고침. 한 단계가 끝나 프로듀서가 테스트 페이지에서 볼 만하면 `origin/main`을 merge → 테스트 → push → 카드 status `test`(테스트 확인) + `next`에 "메인방이 테스트 판에 올려요" → 프로듀서에게 한 줄 + 휴대폰 알림. 전부 끝나 본서버에 넣을 때는 `ready`(승인 대기) + `notes`.
5. 프로듀서가 이 방에 말하는 건 WebGL 관련만. 게임 업데이트·다른 질문은 메인방으로 안내.
6. 단계: 0 시제품·30명 벤치마크(진행 중) → ① 이펙트 빛·블룸·파티클 → ② 코드 그림 몹·몽환의 섬 그림 → ③ UI → ④ 기본값 켜기. 라이브러리는 npm이 열리면 PixiJS(MIT) 가능, 아니면 직접 만든 WebGL2.

## 1단계 (진행 중) — 경로 GL · 빛 번짐
- **일반 경로를 GL로**: 경로를 기기 좌표 점 목록으로 따로 기록(곡선·호는 잘게 나눔) → 채우기: 단순 다각형은 귀 자르기 삼각형(한 배치에 묶임), 꼬인 다각형·구멍·하위 경로 겹침은 **스텐실**(감은 수 nonzero/evenodd 정확) · 테두리: 선 조각마다 사각형(SDF 가장자리), 이음매는 거의 불투명이면 겹쳐 메우고 반투명이면 겹침을 작게. 선형 그라데이션 선도 GL. PC는 MSAA(휴대폰은 끔 · `aden_gl_aa=0`으로 끔).
  - 결과: 2D로 빠지던 경로 **프레임당 567 → 8~12** · 보조 캔버스 올리기 240kpx → 4~23kpx · CPU 몫 23 → **20ms** (p90 31→27.5 · 최악 58→38) · 정확도 0.23%(잡음 0.23%) 통과, 이펙트 장면은 경로 GL 전 2.0% → 0.25%로 오히려 더 같아짐.
- **빛 번짐(블룸)**: `lighter`(더하기)로 그린 것(불·마법·빛·용암 몹)만 반 해상도 빛 버퍼에 한 번 더 그려 가로·세로로 흐린 뒤 화면에 더함. 게임 코드는 그대로. 세기 기본 0.6 · `localStorage aden_gl_bloom=0`이면 끔 · `GLR.bloom(on, k)`. 눈 확인 `dev/tests/gl_bloom.js` → `dev/out/gl_bloom_on.png`.
- **그림자 흐림(shadowBlur)도 GL**: 그림자 켠 그리기는 같은 설정끼리 모아 → 모양 알파를 그림자 색으로 그림자 버퍼에(오프셋) → 그 영역만 가우스 흐림 → 합성 → 모양. 시험 `dev/tests/gl_shadow.js`(사각형·원·선·글자·삼각형·그림) 2D와 큰 차이 0%.
  - 결과: CPU 몫 20 → **14ms** (p90 27.5 → 17.7) · 정확도 0.27%(잡음 0.16~0.26%) 통과.
- **GPU 불티(파티클)**: `GLR.spark(x, y, n, {c, sp, life, g, sz, up})` — 쏠 때만 CPU가 한 번 적고, 움직임(속도·감속·중력·꼬리 늘어남·사라짐)은 셰이더가 시간으로 계산 · 한 번에 8192개 고리 버퍼 · 더하기 합성 + 빛 번짐. game.js 연결 3군데(`// GL:`): 몹 맞을 때 불티(치명타는 더 많이 금빛) · 불 터짐(fireBurst) 불씨 · drawWorld parts 자리에서 `GLR.sparks(g)`. 새 그래픽 꺼짐이면 아무것도 안 함 · 끄기 `aden_gl_fx=0`. 눈 확인 `dev/tests/gl_spark.js` → `dev/out/gl_spark.png`.
- 아직 2D로 가는 것: 무늬/원형(중심 다른) 그라데이션 채우기 · 점선 · 클립 · roundRect/arcTo · 그림자 켠 스텐실 채우기. 개발 표시: `GLR._dbg.on=true` 뒤 `GLR.why()` (`dev/tests/gl_why.js`).
