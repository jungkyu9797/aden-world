# 변신 카드 2차 (갈래 `work/polygacha`) — 인수인계

프로듀서 결정 10/30 2차 설계. 1차(특별상점 뽑기 · 1만 골드 변신 · 11회 확정 · 마일리지 300) 위에 덮어씀. 자세한 1차 조사·구상은 `dev/rooms/polygacha.md`.

## 지금 상태
- 1단계(완료): 위 메뉴 [변신] 창(`polywin` · `btn-poly`/`mm-poly`/`cw-poly`) = 왼쪽 보유중·합성·[다시 뽑기]+변신 칸 / 오른쪽 11회·1회·무료 뽑기(보유 골드) · 마일리지 · 고른 카드 · 최근 결과.
  - 1회 39,900 · 11회 399,000 · 무료 2시간 · 확정 칸 없음 · 마일리지 1000 → 전설 고르기.
  - 합성: 4장 → 다음 등급 (30/30/10/10) · 실패 = 같은 등급 무작위 1장 · 천장(계정) 희귀→영웅 7 / 영웅→전설 10 연속 실패 = 그 실패에 더해 위 등급 1장(숫자 0으로).
  - [자동 합성] = 일반·고급 남김없이 (잠금·변신 칸 제외) · 희귀·영웅은 직접 고르기(트레이, 4장 단위).
  - 변신 칸: 직업마다 1칸(계정 문서 `slot`) · 골드 없음 · 시간 제한 없음 · 쓰러짐/재접속 유지(`PCG.sync` 1초마다) · 빼면 풀림 · 주문서 변신은 그동안만.
  - 특별상점 [변신 카드] 탭은 안내 + [변신 카드 창 열기] 버튼만.
- 2단계(완료): 결과 화면 `#pcg-ovl`(PCG 안 `show`·`deal`·`flip`·`flipAll`·`seqPlay`…·`synShow`).
  - 뽑기: 카드가 가운데로 모였다 펼쳐짐(카드 11장 transform만) · 일반·고급 흰 뒷면 / 희귀 이상 금빛 뒷면(등급 숨김 · 빛·빛줄기·불꽃은 opacity·transform 애니메이션).
  - 금빛 카드 = 전체 화면 `.pcg-big`: 캔버스 카드 비 2.9초 → 다가오는 카드 1초 → 밀어서 결과 확인(강화 연출 `.ef-track/.ef-knob` 모양 그대로, 같은 방식) → 희귀 파랑 · 영웅 보라(두껍게) · 전설 금빛+번개(캔버스+SVG)+여러 번 번쩍. 누르거나 Space·Enter로 단계 건너뛰기.
  - [모두 뒤집기] = 나머지는 바로 · 가장 높은 금빛 1장만 전체 화면. 다 뒤집은 뒤 Space = 같은 뽑기 다시, Enter = 확인, Esc = 닫기(자동 뽑기도 멈춤).
  - 직접 합성(희귀·영웅): 큰 카드(최대 200px, 화면에 맞춤) 금빛 뒷면 · 횟수만큼 뒤집기 · 성공/실패 띠 · 천장 보상은 옆에 한 장 더. 자동 합성은 요약만.
  - [모션 스킵](localStorage `aden_pcg_skip`) = 연출 없이 창의 최근 결과에 바로. [자동 뽑기](이번 접속만) = 마지막으로 산 뽑기를 되풀이 · 영웅 이상(연출 켬이면 이름은 숨기고 멈춤) · 골드 부족 · 창 닫힘이면 멈추고 까닭 표시.
  - 결과 화면이 덮고 있는 동안은 게임 화면 그리기를 멈춤(`window.__pcgCover`, 메인 루프 절전 조건 옆) → 헤드리스 기준 17fps → 40fps.
  - 연출 중엔 창의 '최근 결과'를 숨겨 둠(뒤에서 미리 안 보이게).
  - 테스트용 `PCG._force([카드 id…])` = 다음 뽑기 결과를 정해 둠.

- 3단계(10/31 · 프로듀서가 참고 영상으로 만든 연출을 이 뽑기에 넣기로 함): **뽑기 결과 화면을 TGFX 캔버스로 교체**.
  - 어두운 홀 체크 바닥 · 빛기둥과 함께 카드 뒷면이 세워짐(11회 = 6+5 엇갈림 · 1회 = 가운데 1장) · 희귀 이상은 모두 같은 금빛(등급 숨김).
  - [모두 열기] = 일반·고급만 뒤집힘 → 버튼이 [다음 열기]. 금빛 카드는 누르거나 [다음 열기] → 그 카드로 다가감 → 마법진·기운 → 금이 가며 진짜 등급 색 → 산산조각·번쩍 → 카드 공개(이름·Lv·속도·옵션) → 누르면 홀로(카드 앞면).
  - 키: 연출 중 Space·Enter·누르기 = 공개로 건너뛰기 → 한 번 더 = 홀로 · Esc = 그 연출 끝내기 / 홀에서 Space·Enter = 모두 열기(→ 다음 열기) · 다 열면 Space 다시 뽑기 · Enter 확인 · Esc 닫기. [확인]은 늘 보임(안 연 카드도 받음).
  - 자동 뽑기 = 연출 없이 전부 뒤집고 닫힘(영웅 이상이면 멈춤 — 기존 그대로). 마일리지 전설 고르기(`opt.open`)·합성 결과는 예전 화면(`showOld`·`synShow`) 그대로.
  - 코드: `TGFX`(= window.TransformGacha, PCG 바로 위 한 덩어리 · 원본은 프로듀서 PC `game\src\transform_gacha.js`·데모 `game\tools\transform_gacha_demo.html`) · PCG 안 `show`(새) / `showOld`(예전 1장 공개용) · `artHi`(공개 화면용 큰 그림 캔버스) · `tgSnd`(게임 효과음으로 연결) · `tgUpd`(버튼 상태) · `PCG.ov().tg` 상태 · `PCG._tg()`.
  - 성능: 흐린 카드는 그림자 없이 · 균열·마법진·파편은 shadowBlur 대신 굵은 반투명 선 (헤드리스 홀 59fps · 개별 연출 52fps).
  - 테스트 `dev/tests/polygacha3.js` (뽑기 연출 · 25개 통과). `polygacha2.js`의 뽑기 연출 부분(모였다 펼치기·카드 비·밀어서 확인)은 예전 화면용이라 이제 안 맞음 — 합성 연출 부분만 유효.

## 정한 것 (설명이 모호했던 곳)
- 천장은 "그 실패(돌려받는 카드) + 위 등급 1장 더"로 함.
- 변신 칸은 캐릭터(직업)마다 1칸, 칸에 넣은 카드는 그 장수만큼 보유중·합성에서 빠짐(다른 캐릭터 칸에 있는 마지막 1장은 못 넣음).
- 카드 레벨 제한(일반 1 · 고급 10 · 희귀 20 · 영웅 30 · 전설 45)과 직업 전용(소드·아크)은 그대로.
- [다시 뽑기]는 마지막으로 산 뽑기(1회/11회)를 되풀이(무료는 제외).
