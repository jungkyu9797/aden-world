가로로 돌려 주세요아덴 월드는 휴대폰을 가로로 눕혀서 플레이해요.

아이폰은 웹에서 화면을 직접 돌릴 수 없어요.
① 화면 오른쪽 위 모서리를 아래로 쓸어내려 제어 센터를 열고
② 🔒 화면 방향 잠금을 눌러 꺼 주세요.
③ 휴대폰을 가로로 눕히면 바로 이어져요.

자동 회전이 꺼져 있어요.
① 화면 맨 위를 아래로 쓸어내려 빠른 설정을 열고
② [자동 회전](또는 [세로 모드])을 눌러 켜 주세요.
③ 휴대폰을 가로로 눕히세요. 홈 화면에 앱으로 설치하면 항상 가로로 열려요.

📲 홈 화면에 앱 설치

지금은 카카오톡·네이버 같은 앱 안의 브라우저로 열려 있어서 설치할 수 없어요.
오른쪽 위(또는 아래) 메뉴에서 [다른 브라우저로 열기]를 눌러 Safari·Chrome·삼성 인터넷으로 연 뒤 다시 눌러 주세요.

  1. Safari 아래쪽(아이패드는 위쪽)의 [공유 ⬆] 버튼을 누르세요.
  2. 목록을 내려서 [홈 화면에 추가]를 누르세요.
  3. 오른쪽 위 [추가]를 누르면 홈 화면에 아덴 월드 아이콘이 생겨요.
  1. 브라우저 오른쪽 위 메뉴 [⋮]를 누르세요. (삼성 인터넷은 아래쪽 [≡])
  2. [앱 설치] 또는 [홈 화면에 추가]를 누르세요.
  3. [설치]를 누르면 홈 화면·앱 목록에 아덴 월드 아이콘이 생겨요.

설치하면 주소창 없이 전체 화면 가로 모드로 열려요. 저장은 계정 서버에 되니까 PC와 같은 계정·캐릭터로 이어서 할 수 있어요. (앱으로 처음 열 때는 로그인을 한 번 더 해 주세요)
