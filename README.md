# 아덴 월드 — 업데이트 저장소

PC 실행 파일(AdenWorld.exe)의 로그인 화면 **[업데이트]** 버튼이 이 저장소에서 최신 파일을 받아갑니다.

- `version.json`: 현재 버전과 파일별 크기·SHA-256 목록
- 업데이트는 바뀐 파일만 내려받아 게임 폴더에 덮어씁니다.
